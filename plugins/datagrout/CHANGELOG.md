# Changelog

## 1.0.0 — initial release

- Added the `datagrout` MCP connector pointing at DataGrout's hosted Streamable HTTP
  endpoint (`https://gateway.datagrout.ai/connect`).
- Auth uses OAuth 2.1 with automatic Dynamic Client Registration and PKCE: no API
  key, client ID or server ID to configure.
- Added the `datagrout-mcp` skill and the `datagrout` command.
- Icon: DataGrout's official mark.
